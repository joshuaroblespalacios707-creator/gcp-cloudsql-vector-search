# 🧬 Configuración de Búsqueda Vectorial en Cloud SQL para PostgreSQL

Documentación técnica de un laboratorio práctico de **búsqueda semántica (Vector Search)** en Cloud SQL para PostgreSQL, generando embeddings con **Vertex AI** y consultando por similitud de significado en vez de coincidencia exacta de palabras.

---

## 📌 Resumen y Objetivo

Este laboratorio tiene como objetivo configurar una base de datos Cloud SQL para PostgreSQL para habilitar la **búsqueda vectorial** (*Vector Search*), utilizando embeddings de texto generados por los modelos de IA de Google (**Vertex AI**). Esto permite realizar búsquedas basadas en significado semántico (conceptual), en lugar de coincidencias exactas de palabras clave.

---

## 🛠️ Prerrequisitos y Configuración de Red/IAM

| Paso | Detalle |
|---|---|
| Creación de la instancia | Instancia de Cloud SQL para PostgreSQL (ej. `patent-instance`) |
| Contraseña del superusuario | Contraseña segura para el usuario `postgres`, cumpliendo los requisitos del sistema (ej. `SuperSecret123!`) |
| Permisos IAM | Rol de Usuario de Agent Platform (`roles/aiplatform.user`) otorgado a la cuenta de servicio de Cloud SQL, para permitirle comunicarse con las APIs de Vertex AI |

**Habilitación de flag de integración con Machine Learning:**

```sql
cloudsql.enable-google-ml-integration=on
```

---

## ⚙️ Configuración en Cloud SQL Studio

Conectándose a la base de datos a través de Cloud SQL Studio, se ejecutan los comandos de preparación:

**1. Habilitar extensiones necesarias:**

```sql
CREATE EXTENSION google_ml_integration;
CREATE EXTENSION vector;
```

**2. Otorgar permisos de ejecución:**

```sql
GRANT EXECUTE ON FUNCTION embedding TO postgres;
```

**3. Registrar el modelo de embeddings:**

```sql
CALL google_ml.create_model(
    model_id => 'text-embedding-004',
    model_provider => 'google',
    model_type => 'text_embedding',
    model_qualified_name => 'text-embedding-004'
);
```

---

## 🗃️ Creación de Tabla y Carga de Datos

Se crea una tabla adaptada para almacenar tanto los metadatos de las patentes como su representación vectorial, en un campo de tipo `vector(3072)`:

```sql
CREATE TABLE patents_data (
    id VARCHAR(25),
    type VARCHAR(25),
    number VARCHAR(20),
    country VARCHAR(2),
    date VARCHAR(20),
    abstract VARCHAR(300000),
    title VARCHAR(100000),
    kind VARCHAR(5),
    num_claims BIGINT,
    filename VARCHAR(100),
    withdrawn BIGINT,
    abstract_embeddings vector(3072)
);
```

---

## 🔍 Generación de Embeddings y Búsqueda Semántica

**Generación de vectores para los textos:**

```sql
UPDATE patents_data
SET abstract_embeddings = google_ml.embedding('text-embedding-004', abstract);
```

**Ejecución de la búsqueda por similitud:**

Utilizando el operador de distancia coseno (`<=>`), se realiza una consulta para encontrar los registros más cercanos conceptualmente a una frase de búsqueda:

```sql
SELECT id, title, abstract
FROM patents_data
ORDER BY abstract_embeddings <=> google_ml.embedding('text-embedding-004', 'A new Natural Language Processing related Machine Learning Model')::vector
LIMIT 10;
```

- Uso de la extensión `pgvector` para almacenar y consultar vectores de alta dimensionalidad
- Búsqueda por similitud semántica mediante el operador de distancia coseno (`<=>`)
- Diseño de esquemas híbridos que combinan datos estructurados y representación vectorial en la misma tabla
